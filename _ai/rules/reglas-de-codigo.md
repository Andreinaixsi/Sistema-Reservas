# Reglas de Código

1. Usar nombres claros para variables, funciones.
2. Sigue la estructura modular del proyecto.
3. Toda la lógica de negocio va en la capa de servicios (service.py)
4. Mantener separación entre lógica de negocio, acceso a datos y presentación.
5. Evitar duplicación de código.
6. Documentar decisiones no obvias.
7. Manejar errores de forma controlada.
8. Mantener el proyecto ejecutable con instrucciones claras.
