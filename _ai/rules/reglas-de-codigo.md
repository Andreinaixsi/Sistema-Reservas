# Reglas de Código

1. Usar nombres claros para variables, funciones y clases.
2. Mantener separación entre lógica de negocio, acceso a datos y presentación.
3. Evitar duplicación de código.
4. Documentar decisiones no obvias.
5. Manejar errores de forma controlada.
6. Mantener el proyecto ejecutable con instrucciones claras.
