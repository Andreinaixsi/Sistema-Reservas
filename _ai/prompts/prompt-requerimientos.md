# Prompt para Requerimientos

Analiza el planteamiento del proyecto y ayúdame a redactar requerimientos funcionales claros, verificables y sin ambigüedad. Organízalos con identificadores RF-001, RF-002, etc. Para cada uno incluye descripción, actor, entrada, proceso esperado, salida y prioridad.

Para cada requerimiento funcional, usa esta estructura exacta:

1. RF-001 — [Nombre del requerimiento]
2. Descripción: [Qué debe hacer el sistema]
3. Actor: [Quién lo ejecuta]
4. Entrada: [Datos requeridos]
5. Proceso esperado: [Qué ocurre]
6. Salida: [Resultado]
7. Prioridad: [Alta / Media / Baja]
8. Observaciones: [Opcional]
